# 历史实验结论（V1：比赛阶段）

本文汇总项目在 V1 阶段（比赛开发期间）做过的 A/B 实验。原始报告已从仓库中删除，需要时可以在 Git 历史中找到（`docs/PostTrain/`、`docs/Evaluation/`）。

> **数据边界**：这些实验使用的是比赛方提供的私有数据（AirSim360 仿真序列与真实序列），后端也不全是现在的 ARTrackV2（大部分实验使用 HiT），各报告的序列集合不同。因此下面的数字**只能说明方向**，不能作为对外宣传的指标，也不能在不同报告之间横向比较。对外指标以 [评测记录](evaluation-log.md) 中的 360VOT 结果为准。

## 1. 效率优化：GPU 几何 + 解码流水线（有效）

单条仿真序列，1296 帧，FP32，每帧 8 个视图 / 2 次前向，HiT 后端：

| 方案 | ERP IoU | 球面 IoU | Success@0.5 | P50 | P95 | P99 |
|---|---:|---:|---:|---:|---:|---:|
| 对照组 | 0.1763 | 0.1696 | 0.1462 | 355.9 ms | 501.1 ms | 628.9 ms |
| 仅 GPU 几何 | 0.2138 | 0.2079 | 0.1765 | 90.0 ms | 118.4 ms | 135.4 ms |
| 仅流水线 | 0.2405 | 0.2341 | 0.1979 | 280.6 ms | 325.0 ms | 382.8 ms |
| GPU 几何 + 流水线 | 0.2204 | 0.2148 | 0.1836 | **86.9 ms** | **115.4 ms** | **123.9 ms** |

- 组合方案的 P50 延迟降低约 75.6%，P99 降低约 80.3%；
- GPU 几何与 CPU 实现的像素回归误差：P99 为 0，最大 1 个灰度级；
- 精度差异来自单条序列上的状态轨迹变化，不能解释为几何本身提升了精度。

**结论**：方向有效，需要在 ARTrackV2 + 360VOT 上重新测量后才能对外使用。

## 2. 精度增强实验（均未进入默认路径）

| 方向 | 最好的信号 | 主要问题 | 决定 |
|---|---|---|---|
| 第二轮直接从 ERP 原图裁剪（2x / 4x） | 2x relaxed 的 Success@0.5 提高；4x 在一条序列上 IoU 0.176 → 0.207 | 硬回归序列上 IoU 下降 0.17–0.23，丢失率增加 37–53 个百分点；触发率接近 100%，相当于替换了整个第二轮 | 不采用 |
| 框回归 refinement head（delta） | 一条序列 ERP IoU +0.0118 | 候选级局部 IoU 没有稳定提升，收益来自状态轨迹变化 | 仅作研究起点 |
| quality-aware refinement | 两条序列 IoU 提升 | 真实序列 success 下降 3.09 个百分点、丢失率恶化 5.30 个百分点 | 不采用 |
| 尺度约束（scale clamp） | 三序列宏平均 IoU 有正信号 | 目标消失时的误报率恶化 | 需要配合 presence 门控 |
| 时序形状先验 | 一条序列有局部收益 | 错误框形成自反馈，硬回归序列明显下降 | 停止 |
| 动态模板更新（strict / relaxed） | 宏平均 ERP IoU 0.3116 → 0.3157 / 0.3208 | 按帧加权的 IoU 几乎不变（0.2740 → 0.2712 / 0.2750），多条序列下降，回滚频繁、额外开销大 | 默认不启用（ARTrackV2 阶段改为保留 anchor 的 recent 模板） |

## 3. 经验总结

1. **平均 IoU 不能单独决定是否采用**。多个方案出现“平均 IoU 上升，但丢失率、Success@0.5 或消失目标误报率恶化”的情况。采用新方案时必须同时检查：ERP IoU、球面 IoU、Success@0.5、丢失率、消失目标误报率和 P95 延迟。
2. **建立“硬回归序列”作为早停门槛**。每个新方案先在已知容易出问题的序列上跑，没通过就不扩大实验范围，节省大量算力。
3. **自反馈是最大的风险**。直接 ERP 裁剪、形状先验和动态模板都会改变后续帧的输入分布：单帧检查通过，不代表长期安全。需要持续收益检查和独立的回滚依据。
4. **门控信号必须在线可观测**。只看裁剪是否越界、分数排名或形状相似度，不足以预测未来收益。更有价值的信号是：连续的测量接受情况、presence 概率、尺度变化量、目标在视图中的占比。
5. **一次只改一个变量**。同时修改裁剪尺度、触发条件和视场的实验，结论无法归因。
