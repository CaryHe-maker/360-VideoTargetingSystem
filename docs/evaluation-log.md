# 评测记录

本文是 Track360 **所有评测结果的长期记录**。每跑完一轮评测，就在第 3 节追加一条记录，并更新第 2 节的汇总表。**只追加，不修改、不删除历史记录**；发现某条记录有错误时，追加一条更正说明。

- 数据集选型和评测协议见 [benchmark.md](benchmark.md)；
- V1（比赛阶段）在私有数据上的实验结论见 [experiments.md](experiments.md)，不与本文的数字混在一起比较。
